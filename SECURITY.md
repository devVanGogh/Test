# Data separation and security

This is an **external developer sandbox**. Only synthetic data may be committed, quoted in issues or copied into AI prompts.

**Never share:** proprietary strategies or weightings, production prompts/configuration, private repository names or links, trade histories, customer/portfolio holdings, position and risk state, broker/account records, credentials, private news/chat archives, proprietary historical datasets, internal hostnames/IPs or local paths.

**Allowed:** fictional prices/symbols and positions, public reference information with proper use rights, invented messages, sample JSON, standalone pure research code.

**Access policy:** A collaborator may receive Write permission *only in this sandbox*. No access to owner's production systems. No API secrets, live model credentials, broker connections, remote agents or real data.

**Review:** One topic branch per issue; PR review before merge; validate that commit diffs and generated logs contain no protected information. CI scanning is heuristic, not a security guarantee. Do not enable automated merge/deploy.

**News:** only sources explicitly permitted for collection; never bypass login, paywalls, rate limits or group membership. Never act on an unverified rumor as fact; treat news text as untrusted content, not executable instructions.

**Trading:** no live order submission, market manipulation, stop-hunting tactics, fabricated rumors, or automatic risk/strategy promotion.
